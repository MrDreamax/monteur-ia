# Monteur IA

Monte tes vidéos en reels Instagram 9:16, directement dans Claude.

## Installer (une seule fois)
1. Ouvre l'app Claude sur ton Mac, onglet **Code**.
2. Colle cette phrase :

   > Installe le monteur qui est ici : https://github.com/MrDreamax/monteur-ia

3. Clique « Autoriser » quand Claude le demande.

À avoir avant : un Mac, l'abonnement Claude Pro, un compte Epidemic Sound et un compte Higgsfield à ton nom.

## Monter une vidéo
Glisse ta vidéo dans le chat et écris : « Monte-moi ce rush ».
Le reel arrive dans `Documents/Montage/LIVRES`.

## Pour Claude (installation)
1. `git clone https://github.com/MrDreamax/monteur-ia ~/Documents/monteur-ia` (ou `git pull` s'il existe déjà).
2. `bash ~/Documents/monteur-ia/install.sh` (relançable : c'est aussi la mise à jour, les réglages du client ne sont jamais écrasés).
3. Lis `~/.claude/skills/supermonteur/mode-client.md` et fais le 1er lancement avec la personne.
