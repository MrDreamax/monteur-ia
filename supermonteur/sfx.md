# Sons du Monteur

## Choisir un SFX à l'oreille : CLAP (25/10)
CLAP = l'outil qui reconnaît les sons (installé à part, mode d'emploi `~/.local/edit-tools/README.md`). Toujours son Python à lui : `PY=~/.local/edit-tools/.venv/bin/python`, préfixe `TOKENIZERS_PARALLELISM=false PYTHONUTF8=1`. JAMAIS installer transformers / torch 2.2 dans le python3 système (le moteur y a torch 2.8 + numpy 2 + faster-whisper).
- **Index** : `sfx_index_clap.txt` (dossier du skill) = chaque son de `/Volumes/son disque externe/1 - Contenu/1 - Bibliothèque/Sons` → durée + 3 étiquettes CLAP avec leur score. Chercher d'abord par le préfixe du nom (whoosh, swoosh, pop, ding, impact, riser…), puis vérifier avec l'étiquette. Sons longs (ambiance, drone, > 5 s) : étiquettes peu fiables, se fier au nom. Son ajouté au SSD : relancer `$PY ~/.local/edit-tools/scripts/listen.py label "<dossier Sons>" > sfx_index_clap.txt`.
- **SFX d'une vidéo de réf** : musique forte → Demucs d'abord (`$PY -m demucs -n htdemucs -o stems clip.wav`), puis `$PY listen.py events stems/htdemucs/clip/drums.wav` (et `other.wav`) ; sans musique, `events` direct sur la vidéo (`--sensitivity 2.2` si c'est chargé). Puis pour un son repéré : `ffmpeg -ss <début> -to <fin> -i ref.mp4 -vn -ac 1 piece.wav` et `$PY listen.py match piece.wav "<dossier Sons>" --top 5` = les sons de son disque externe qui lui ressemblent le plus.
- Sous une voix, CLAP prend des syllabes pour des sons : séparer d'abord. Les mots = Whisper ; CLAP = tout le reste.
- Ne JAMAIS dire « je ne peux pas écouter l'audio » : Whisper pour les mots, CLAP pour les sons, et dire à quel point on est sûr (le score).
- Les règles SFX ne changent pas : minimalistes, calés au pic, licence Epidemic / SSD.
- **Ordre des sources de SFX (26/10, mesuré par `earshot sfx check` : earshot 12/12 propres, Openverse 3/12)** : Epidemic / SSD d'abord, puis earshot (`fabrique`), puis le libre en DERNIER recours. Un son libre gardé passe `earshot sfx check` avant d'entrer dans un montage.
- **Sons gratuits CC0 (26/10)** : pas de son qui colle, client sans Epidemic, ou pub Meta (plan Creator = organique seulement) → `python3 $S/kit_sfx.py libre <clé> [<terme>]` (5 choix Openverse / Freesound, CC0 seulement) puis `--pose <n>`. Preuve de licence dans `~/Documents/Montage/SFX/_kit.json`. Qualité inégale : écouter (CLAP) avant de garder.
- **Sons fabriqués en code : earshot (26/10)**, installé dans `~/.local/earshot` (son propre Python, 1 Go ; JAMAIS dans le python3 système). 252 sons (whoosh, riser, impact, sub drop, pop, clic…), 0 droit à payer, pub Meta OK. `python3 $S/kit_sfx.py fabrique <clé> [<id>]` (ou `fabrique manque`) ; liste des id : `~/.local/earshot/.venv/bin/earshot sfx list`. Chaque rendu donne l'instant du pic (`peak at`) = caler ce pic sur le mot. Contrôle d'un son : `earshot sfx check <fichier>`.
