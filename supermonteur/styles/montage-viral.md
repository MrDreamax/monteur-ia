1. **Étape 1 SANS `cadre.py`** (il zoome et mange la place au-dessus de la tête) : simple mise au format `ffmpeg -i rush.MOV -map 0:v:0 -map 0:a:0 -vf "scale=1080:1920:flags=lanczos,fps=30" -c:v libx264 -crf 16 -c:a aac -b:a 192k rush.mp4` (iPhone : rotation appliquée toute seule). Puis étapes 2-3 (transcription, dérush) → `clip.mp4` + `words.json`. **Relire words.json mot par mot** : Whisper écrit « c'est tier » pour C tier, « bê / b » pour B, « à » pour A, « dé / d / des » pour D, « est » pour S ; corriger le texte (garder les timings).
2. **plan.json** : `cam`, `words`, `fixes`, `music` (Epidemic, émotion), PAS de `title`, `bigwords`, `numbers` (ils occupent la zone du tableau) ; `keywords` possibles seulement si les sous-titres restent ≤ 1340 px (le script les retire sinon). + le tableau, calé sur SES mots (chercher l'instant de chaque mot dans words.json) :
   - **T** : `"viral": {"t": {"title": {"sans": "Meta Verified", "serif": "pour qui&#8239;?", "at": 0.68}, "bar_at": 1.15, "left": {"head": "PAS POUR TOI", "icon": "cross", "at": 2.40, "items": [["frimer", 3.70], ["te la péter", 5.04]]}, "right": {"head": "POUR TOI", "icon": "check", "at": 6.86, "items": [["entrepreneur", 7.72], ["tu crées<br>du contenu", 8.66]]}, "win": {"at": 10.06}}}` ; `title.at` = quand il annonce le sujet ; `bar_at` ≈ +0,5 s ; en-tête de colonne = le mot qui l'ouvre (« pas fait pour toi », « par contre ») ; élément = le mot exact ; `win` = sa conclusion (« oui, je te le recommande ») : la colonne perdante se grise et se barre, la gagnante grossit avec un halo. 2 éléments max par colonne, SES mots condensés (1-3 mots, `<br>` pour 2 lignes).
   - **Mauvais / bien / excellent** : `"viral": {"mbe": {"title": {"sans": "Ta bio", "serif": "Instagram", "at": 0.27}, "cards": [{"label": "Mauvais", "at": 1.02, "img": "ins/bio-mauvais.png", "text": "Floue"}, {"label": "Bien", "at": 1.71, "img": "ins/bio-bien.png", "text": "Une promesse"}, {"label": "Excellent", "at": 3.00, "img": "ins/bio-excellent.png", "text": "Promesse, preuve, action"}], "win": {"at": 3.6}}}` → 3 cartes de gauche à droite (l'ordre où il les montre du doigt), pastille couleur (rouge / ambre / bleu) + **IMAGE** qui illustre (Cyril 16/10 : « des images pour illustrer, avec un petit texte juste en dessous ») + petit texte serif dessous. Images = VRAIS exemples (fausse bio refaite en HTML puis capture Chrome, capture d'écran, produit) ; sans image → icône tracée (croix / vague / étoile). `win` = la meilleure carte s'allume (halo), les autres se grisent. Si la vidéo est très courte, garder 2-4 s après le dernier mot pour qu'on lise (rush : il reste immobile avant de couper).
   - **Tier list** : `"viral": {"tier": {"title": {"sans": "Tier list", "serif": "des formats Instagram", "at": 0.15}, "rows": ["S", "A", "B", "C", "D"], "items": [{"img": "ins/podcast.png", "label": "Podcast", "text": "Podcast", "at": 1.95, "to": "S", "land": 2.56}, ...]}}` → rangées de couleur classique (S rouge, A orange, B jaune, C vert, D bleu). Titre en grand au début, puis il s'efface et le tableau prend toute la zone (`title_hide: false` pour le garder). Chaque élément = **ICÔNE + son nom DANS la tuile en Montserrat** (Cyril 16/10 : « pas du texte », « le texte dans l'icône, même police que le montage ») : grossit au CENTRE (220 px) quand il est nommé (`at`), file dans sa rangée quand il dit la lettre (`land`), la lettre s'allume. Construire `items` en lisant words.json : élément = mot qui le nomme, `land` = la lettre qui suit.
   - **Hook plus fort + son à chaque note** (Cyril 17/10, tier list v3 : demandé par lui, version A gardée) : `title.size: [96, 110]` (MAJUSCULES / serif, défaut 34 / 76 = trop petit) + impact au titre (`impact-boom-dark-cinematic`, 0,12 s, `align: start`) ; à chaque élément, `SFX/epidemic/tier-land.wav` (whoosh + claquement de carte, pic à 0,33 s) PIC calé sur l'arrivée de la tuile (`at` = max(land, at + 0,35) + 0,40, sans `align`), `volume: 0.4` (~6 dB sous le mix : à 0,3 on ne l'entend pas pendant qu'il dit la lettre, à 0,5 il passe devant). Liste `sfx` écrite dans plan.json (remplace les SFX auto). Réf : `livrables/montage-viral-6731-v3/plan.json`.
   - **Icônes de la tier list** (validées 16/10, seule image générée de ce style) : Higgsfield `gpt_image_2_5`, `background: transparent`, `quality: high`, `1k`, 1:1 (1,5 crédit l'une ; lots de 5 max, sinon limite de débit 429 = rien n'est débité, relancer).
