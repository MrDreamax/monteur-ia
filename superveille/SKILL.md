# SuperVeille

Jamais le mot « voler » : on dit « reprendre ». Traduire une vidéo mot pour mot est autorisé.

- Ouvre l'appli : `bash ~/Documents/SuperApps/ouvrir-super.sh veille`. C'est la personne qui coche, pas toi.
- Mes enregistrés : lit la session Instagram déjà ouverte dans Chrome. Lecture seule, rien n'est écrit sur Instagram.
- 1er lancement : macOS demande l'accès au trousseau pour Chrome. La personne clique « Autoriser ».
- Transposer : remplis d'abord avec elle `~/Documents/SuperApps/superveille/ma-marque.md` (cible, sujets, voix, appel à l'action).
- Recherche : demande le connecteur Apify dans Claude. Scanner cerveau : demande le connecteur Higgsfield. Sans eux, le reste marche.
